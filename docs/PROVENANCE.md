# Provenance

BenScr.Spatial is an original point-index implementation for this package. It includes no
third-party spatial library, engine sources, wordlists or external runtime dependency.
The C++ standard library provides the containers, sorting and numerical primitives.

Build, packaging and verification configuration is adapted from the public BenScr.Noise
repository at commit `4694d53ce5086017037434aa99f6f91698386124`.

The original Ben Schneider license is copied unchanged into `LICENSE.txt`:
SHA-256 `ffed6ed7241c89d7bb6f956f96d8e9333b5f2d755aa5d2cc29526768b932a8f0`.
It is a custom license requiring attribution; it is not identified as MIT.

`branding/BenScr_Icon_Master.png` is the unchanged shared BenScr original, also embedded
as `icon.png` in the NuGet archive. It is a transparent RGBA PNG, 1254 by 1254 pixels,
795819 bytes, SHA-256 `a5dcabceb766e13c1840a95130ee98a458e12e3713fd9b07f3ceae75a1f5b993`.
No recoloring, redrawing or resized replacement is used.
